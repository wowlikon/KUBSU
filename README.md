# KubSU | Решения заданий и лабораторных работ

Репозиторий с практическими заданиями, лабораторными и домашними работами студента КубГУ.

### Структура репозитория
* **Git-ветка** = отдельная дисциплина
* **Папка внутри ветки** = конкретная лабораторная работа или задание
* **README.md** = описание и ссылки переходов

## Как работать с репозиторием локально

```bash
# 1. Клонируем репозиторий
git clone https://github.com/wowlikon/kubsu.git
cd kubsu

# 2. Переключаемся на ветку нужной дисциплины
git checkout discipline
```

### Для создания веток дисциплин
Чтобы в ветке дисциплины не тянулся файл `README.md` от `main` (или чтобы там был свой отдельный мини-ридмик конкретного предмета), ветку дисциплины можно создать как полностью независимую (orphan):

```bash
# Создать пустую ветку без истории main
git checkout --orphan new
git rm -rf .

# Добавляешь файлы лаб этой дисциплины и коммитишь
git add .
git commit -m "feat: init new discipline"
git push -u origin new
```
